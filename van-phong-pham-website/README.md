# Van Phong Pham Website

Dự án website cho **cửa hàng văn phòng phẩm**, được sắp xếp lại thư mục theo *chuẩn của lập trình viên*.

| Thư mục | Nội dung |
|---|---|
| docs | Tài liệu, ghi chú nhập hàng |
| media | Hình ảnh, logo |
| data | Dữ liệu đơn bán (Excel) |
| logs | File log và báo cáo lỗi |
| backup | Bản sao lưu |

## Liệt kê nội dung dự án

```powershell
Get-ChildItem -Recurse -Force
```
